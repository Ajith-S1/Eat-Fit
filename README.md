# Eat-Fit

Eat-Fit is a polished and modern front-end website for a healthy food delivery brand. Designed with clean visuals, responsive layouts, and intuitive navigation, this project showcases a professional UI for meal selection, menu browsing, and customer engagement.

## 🚀 Highlights

- **Responsive design** optimized for desktop, tablet, and mobile
- **Healthy food delivery concept** with a stylish, user-centric interface
- **Structured assets** for CSS, images, and vendor libraries
- **Multiple pages** including home, menu, and fast food sections
- **Easy customization** for branding, content, and menu updates

## 💡 Why Eat-Fit?

Eat-Fit delivers a modern experience built around the idea of healthy living and convenience. It emphasizes visual appeal, fast loading layouts, and easy access to food choices for users who want a clean, trustworthy online ordering experience.

## 🧩 Project Structure

- `index.html` — main landing page
- `menu.html` — primary menu page
- `css/style.css` — core styling for the main site
- `FoodWeb/` — specialized menu and fast-food pages with dedicated styles
- `resources/` — shared images and CSS assets
- `vendors/` — external library styles and font assets

## 📁 Included Pages

- **Home Page** — attractive hero layout and introductory content
- **Menu Page** — organized food categories and item presentation
- **Fast Food Section** — dedicated area for quick meal selections

## 🛠️ Technologies

- HTML5
- CSS3
- Responsive layout techniques
- External vendor styles for enhanced presentation

## ✨ Notes

This repository is a great starting point for a healthy food delivery website. It can be extended with animation, interactive menus, and backend integration to create a full production-ready platform.
